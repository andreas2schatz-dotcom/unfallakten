Bearer-Token-Authentifizierung
Alle Endpunkte außer /auth/login, /auth/register/erster, /health und /auth/ping erfordern einen gültigen JWT Access Token (60 Min. Laufzeit). Nach Ablauf über /auth/refresh erneuern. Für Admin-Endpunkte (Benutzer löschen, Akten löschen) ist die Rolle admin erforderlich.
Authorization: Bearer <access_token>
